Privacy Policy

Random One Arena Studio · Effective date: October 5, 2026

What the application does

Random One Arena Studio is a private desktop application run by the owner of the Random One Arena YouTube channel on their own computer. It uploads videos produced by the owner to the owner's own YouTube channel and reads that channel's scheduled and published videos to display a publishing calendar.

Google user data the application accesses

The application uses the YouTube Data API with the following permissions:

  • youtube.upload — to upload the owner's videos to the owner's channel.
  • youtube — to set titles, descriptions and publish times of those videos, and to list the channel's own scheduled and published videos.

The application does not access any other Google account data.

How data is stored

OAuth access and refresh tokens are stored only on the owner's computer, in a local file readable only by the owner's user account. The application has no server, does not use analytics, and does not send any data anywhere other than to Google's YouTube API.

Sharing

No data is shared with, sold to, or transferred to any third party.

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions. Deleting the local token file also removes the application's access from the computer.

Contact

Questions about this policy can be sent through the Random One Arena YouTube channel.
